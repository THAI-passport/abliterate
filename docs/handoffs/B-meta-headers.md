## 1. Metadata in Base.astro
- Props: `title`, `description`, optional `image` (default `/og/default.png`).
- Add `<link rel="canonical">` from `Astro.site` + `Astro.url.pathname` (trailing slash consistent with
  what Pages serves: it 308s `/pricing` to `/pricing/`).
- Open Graph: `og:type` website, `og:site_name` abliterate, `og:title`, `og:description`, `og:url`,
  `og:image` (absolute URL, 1200x630), `og:image:alt`. Twitter: `summary_large_image`.
- `<meta name="theme-color">` for light and dark (`media=` attribute), values matching `--paper` tokens.
  Note in a comment that meta tags cannot read CSS variables, so this is the one allowed duplicate.
- JSON-LD `Organization` + `WebSite` on the landing only. No `Product`/`Offer` schema: nothing is for sale and
  the models are fictional; structured prices would present them as real (AGENTS hard rule).
- Every page already has a description? Check all 18 built pages; list any missing in P15.
