### Start here (`/start`)

**Title.** Start here | abliterate
**Meta description.** A guide for people who have never used an API: what it is, how to get a key, and how to send a first request. Planned: nothing here works yet.
**H1.** Start here
**Intro.** This guide is for people who have never used an API. Every step is planned: the API does not exist yet, so nothing here works today. It will read the same when it does.

**1. What an API is.** An API is a counter you order from. You send a request, such as a question. The service sends back a response, such as an answer. A chat app does this for you. With an API you do it yourself, or you let another app do it for you.
What you should see: nothing. This step is vocabulary.

**2. Join the waitlist and get a key.** Join the waitlist. When a model exists, you will get an email with a link to create an account and a key. A key is a long string of characters that says who is asking and who gets billed.
What you should see: an email, and a key that starts with `ab-`.

**3. Keep the key private.** Treat the key like a password. Do not post it, commit it to a public repository or send it to anyone. If it leaks, delete it in your account and make a new one. Anyone with your key spends your credits.
What you should see: the key in a password manager or an environment variable, and nowhere else.

**4. Send a first request with curl.** curl is a command-line tool that sends requests. It comes with macOS, most Linux systems and recent Windows.
```bash
curl https://api.abliterate.app/v1/chat/completions \
  -H "Authorization: Bearer ab-demo-not-a-real-key" \
  -H "Content-Type: application/json" \
  -d '{"model": "abliterate-sonny-v2.5", "messages": [{"role": "user", "content": "Say hello."}]}'
```
What you should see: a block of text. The reply is under `choices`, then `message`, then `content`.

**5. Do the same in Python.** Install the library with `pip install openai`, then run the sample from the home page with your own key.
What you should see: the reply, printed in your terminal.

**6. Connect an app.** SillyTavern and Open WebUI both accept a custom OpenAI-compatible endpoint. In the connection settings choose the OpenAI-compatible option, paste `https://api.abliterate.app/v1` as the base URL, add your key and pick a model id such as `abliterate-sonny-v2.5`.
What you should see: the model in the app's model list, answering when you type to it.

**7. When something goes wrong.**
- 401: the key is missing or wrong. Check it.
- 402: you are out of credits. Top up.
- 404: the model id is misspelled. Copy it from the models page.
- 429: too many requests. Wait a moment and try again.
- 5xx: a problem on the service side. Try again in a minute, then check the [status page].
- If every request fails and the status page says the API is planned, that is why.

**Closing call.** Join the waitlist. (Same button and line as elsewhere.)

### FAQ (`/faq`)

**Title.** FAQ | abliterate
**Meta description.** Answers about the planned models, credits and plans, privacy and limits, and who is behind abliterate.
**H1.** FAQ

**The models**

1. **Do these models exist?** No. Every model on this site is fictional and nothing can be run yet. The storefront, the waitlist and the plan to build the service are real. The rest is pending.
2. **What does "abliterated" mean?** Abliteration finds the direction in a model's internal activations that is linked to refusing a request, and removes it. The result is an uncensored model: it answers instead of declining. Quality can shift in the process, so each model is planned to be tested against its original before release.
3. **Will it answer anything?** No. The models decline far less often than ordinary ones, but the service has limits, and the acceptable use policy lists them. The models also make mistakes, and they make them confidently. "Yes" was a headline, not a contract.
4. **Is it OpenAI-compatible?** Yes, as planned. The chat completions endpoint will accept the OpenAI request format, so most clients work after changing the base URL and key. Streaming and tool calling are planned. The compatibility list will be published with the docs.
5. **Who is this for?** Developers who want an API for models that do not refuse, and people who want uncensored AI and have never used an API. The [Start here] guide is written for the second group and is useful to the first.

**Money**

6. **When will it launch?** There is no date. The launch depends on funding for inference, and the funding is the dev. Joining the waitlist gets you one email when a model exists.
7. **How do credits work?** A credit is a prepaid dollar: 1 credit equals $1 of usage. Each request costs the model's rate for the input and output tokens used. Credits expire 12 months after they are granted or bought. All billing is planned and may change before launch.
8. **What do Free, Pro and Max include?** Free is the trial, Pro is for regular use and Max is for heavy use. Allowances and prices are on the [pricing page]. All three are planned.

**Privacy and rules**

9. **Do you log my prompts?** No. Once the API exists, prompts and completions are never stored and never used for training. Billing metadata is kept for 90 days: key ID, time, model and token counts. The [privacy page] has the details. Currently there is nothing to log.
10. **Can I resell access?** Building a product on the API is fine. Passing on your key is not, and the acceptable use policy prohibits it.
11. **Is it legal?** Using open-weight models is legal in most places. What you generate is your responsibility, and laws differ by country. abliterate gives no legal advice. Any use that is illegal where you live is already prohibited by the acceptable use policy.

**The dev**

12. **Who is behind this?** One person, called the dev on this site. The dev builds the site, writes the copy and answers the email. A company name will appear here once there is a company. The dev would like it noted that the dev is also the support team.
13. **Why is the dev's PC mentioned so often?** It is the only GPU the dev owns, and it is a GTX 750. It appears on a few pages. It never appears on pricing or legal pages, where it has no business.
14. **How do I contact you?** Email hello@abliterate.app. A person reads it, and it is the same person who wrote this page.

**Title.** Privacy | abliterate
**Meta description.** What abliterate stores today, and the no-logging pledge for the service once it exists.
**Status line.** Draft, 2026-10-08. For legal review before launch.

**What is stored today.** The waitlist stores your email address and the time you agreed to join. Nothing else about you is stored.

**Analytics.** The site uses Cloudflare Web Analytics. It sets no cookies and identifies no one. It reports aggregate counts such as page views.

**Who processes the data.** Buttondown sends the waitlist emails and holds the list. Cloudflare hosts the site and provides the analytics. Payments, once they exist, will go through a payment provider: [CONFIRM: provider]. Card details never reach the operator's servers.

**The no-logging pledge.** This applies once the API exists. Prompts and completions are never stored and never used for training.
